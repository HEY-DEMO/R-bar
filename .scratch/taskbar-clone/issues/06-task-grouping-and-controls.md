# 06: Task Grouping & Window Activation Controls

**What to build:** Ergonomic task management on the bar, clustering multiple windows of the same application under a single task icon, with full click controls to activate, minimize, or close target windows.

**Blocked by:** 05: Shell Hook Window Tracker & Qualification Filter

**Status:** ready-for-agent

- [ ] Clusters multiple window instances belonging to the same application under one grouped task item by application identifier or process path.
- [ ] Displays a visual count badge or multi-window indicator when a task item represents multiple windows.
- [ ] Left-clicking an inactive task item brings that window to the foreground and restores it if minimized.
- [ ] Left-clicking an already active task item minimizes that window.
- [ ] Right-clicking a task item opens standard window commands (Minimize, Maximize, Restore, Close) via standard system commands.
